Prove you're fit to ride. In about thirty seconds.

OK2Ride is a standalone web component, <ok2ride-check>, that runs a short, randomised cognitive check before a shared e-scooter or e-bike unlocks. Every run draws tests from a pool of eight, measures reactions to the millisecond, and hands your backend a result it can verify.

Events

Start a check to see stage-change, capability-passed and capability-failed events here.

Eight tests, drawn at random

Each run shuffles the pool and presents stage-count tests one after another, with a short intro before each. The run stops at the first failed test. Difficulty tunes tolerances and error allowances; the reaction thresholds never change.

PVT Reaction

After a random 1.5–4.5 s wait the panel flashes yellow. Tap as fast as you can, three clean taps in a row. Measures vigilance, the strongest single indicator of impairment and fatigue.

Pass RT 100–450 ms is valid; over 450 ms is a lapse; under 100 ms is a false start. Lapses within max-lapses.

STR Steering

Rotate a handlebar into a highlighted arc by dragging (or tilting the phone) and let go. Measures motor control and spatial judgement.

Pass Released within ±5° of the target inside 3 s on medium.

GNG Go / Stop

Six signals: tap fast on green GO, hold back on red STOP. Measures response inhibition, which alcohol degrades early.

Pass At most one false tap and one missed GO on medium; zero false taps on hard.

TRL Number trail

Numbers scattered on a board; tap them in ascending order against the clock. Measures visual scanning and sequencing (Trail Making Test A).

Pass 1 to 8 in order within 12 s with at most two wrong taps on medium.

SEQ Pattern memory

Tiles light up in turn; repeat the pattern. Measures working memory span.

Pass A 4-tile pattern repeated exactly within 8 s on medium; 3 on easy, 5 on hard.

CLR Colour match

A colour word appears in a different ink; tap the ink colour, not the word. Measures interference control (Stroop).

Pass Five rounds with at most one wrong or unanswered on medium.

TME Time sense

A target interval is named, then nothing on screen counts it down. Tap when you judge it has passed. Measures internal timekeeping, which drifts under fatigue and alcohol.

Pass Two rounds judged within ±0.5 s on medium; ±0.7 s on easy, ±0.35 s on hard.

ODD Odd one out

A field of identical letters hides one confusable different one — a T among Ls, an O among Qs. Find it and tap it before the round runs out. Measures visual search and scanning speed.

Pass Three rounds of twelve symbols with at most one wrong or unfound on medium.

How it works

  1. DrawThe component shuffles the pool and picks the tests for this run. The rider sees what to expect, then a Go button before each test.
  2. MeasureInputs are timestamped with performance.now(); flash stimuli are revealed on an animation frame so onset is sampled right before the paint.
  3. VerifyThe result event carries per-test metrics and a checksummed token bound to your nonce. Validate it on the server before unlocking.

Install

Drop the module on the page, or import it from npm. Importing registers the element; nothing else is required.

<script type="module" src="/ok2ride.js"></script>

<ok2ride-check
  stage-count="2"
  difficulty="medium"
  challenge-nonce="nonce-from-your-server"
></ok2ride-check>

Listen

Two events decide the outcome. Both bubble and cross shadow boundaries.

const el = document.querySelector('ok2ride-check');

el.addEventListener('capability-passed', (e) => {
  // send e.detail.verificationToken to your backend
});

el.addEventListener('capability-failed', (e) => {
  console.warn(e.detail.failureReason, e.detail.failedTest);
});
